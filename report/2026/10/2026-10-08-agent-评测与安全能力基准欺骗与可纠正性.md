## 3. 蓝海与缺口（Blue Ocean & Gaps）

**一句话增量**：本周期暴露的**结构性空白**不是"再做一个基准"，而是**评测的元层（披露、口径、复现）**与**多智能体/工具使用场景下的忠诚度测量**。

1. **评测披露的标准化空白（最明确的蓝海）**：[5] 的动机本身就是缺口陈述——"两篇论文在同一基准上报同一模型名的结果会互相矛盾"，且 12 篇论文的披露维度参差，作者因此提出**开放评分 schema**（[5]，2026-05）。**没人做的事**：把"评测卡/披露元数据"变成强制字段并被主流榜单采纳。
2. **多智能体关机安全**：[22]（2026-09）明确指出该问题此前多在单 Agent 设定下讨论，**多智能体下的干预规避**是空白（[22]）。
3. **computer-use Agent 的可纠正性**：[23]（2026-06）将可纠正性评测落到真实工具调用域，此前评测多停留在文本/玩具环境（[23]）。
4. **评测的成本与能耗轴**：[3]（生产重复评测成本）与 [8]（issue resolution 能耗）共同指向一个空白——**没有把"每单位能力提升的算力/能耗"作为基准报告的常规字段**。
5. **纵向时效评测**：[13]（2025）证明模型性能会随时间衰减，而绝大多数 Agent 基准仍是**一次性截面**。把"时间"作为评测维度的 Agent 基准是空白（[13] 提供方法学，[3] 提供工程动机）。
6. **具身 / VLA Agent 的欺骗与可纠正性评测**：本轮来源**零命中**。这是一个明显无人区——但注意：**该判断基于"本轮检索为空"，属检索性判断而非领域性结论**，`> 待核实`（需专门检索确认是否已有工作）。

## 4. 瓶颈与拐点（Bottleneck & Inflection）

**一句话增量**：瓶颈从"**能力不足**"转向"**评测可信度不足**"；拐点信号是评测组织方式从"静态榜单"转向"**纵向 + 对抗 + 元审计**"三件套。

**瓶颈清单**

| 类型 | 具体瓶颈 | 证据 |
|---|---|---|
| 算法/效度 | 同名模型 + 同一基准 → 结果互相矛盾，说明**评测口径披露不足**，是当前最尖锐的效度瓶颈 | [5] |
| 成本/算力 | 全量 Agent 基准重跑昂贵，生产演化中的 Agent 需要高频复评 | [3] |
| 能耗 | Agentic issue resolution 的能耗成为可测成本项 | [8] |
| 时效 | 模型性能随时间衰减，截面评测结论会过期 | [13] |
| 复现 | [19][21][22][23] 均为**单团队评测设计**，本轮**未见任何独立复现/第三方榜单交叉验证** | [19][21][22][23] |

**拐点信号（可观测指标）**
- **信号 A**：2025-06 → 2026-09 之间，欺骗/破坏类评测**从单 Agent 扩展到多智能体与 computer-use**（[21]→[22]/[23]），表明"忠诚度评测"正在从概念验证进入场景化。
- **信号 B**：出现"**审计基准论文本身**"的论文（[5]）与"**生产环境重复评测**"（[3]），表明社区开始把评测当作**需要被评测的对象**。
- **信号 C**：治理侧出现**连续三版**的透明度指数（[18]），说明评分机制已具备**年度复现的稳定性**。

> **Goodhart / 刷分争议**：本轮**未命中**任何关于基准污染或榜单刷分的实证批评来源，`> 待核实`（不得以常识替代证据）。
