## 1. 进展与热点（Progress & Hotspots）

**一句话增量判断**：2024–2026 的实质增量集中在"**弱到强泛化（Weak-to-Strong Generalization, W2S）作为可扩展监督的可实验代理**"与"**弱监督信号的形态升级（从标签/偏好 → critique / 集成投票）**"两条线上；校准与不确定性则是以"集成"这一旧工具在 RL 探索与安全评测中被重新拾起，尚未形成与对齐训练的闭环。

### 1.1 可扩展监督：从"弱监督者不可靠"到"弱 critic + 集成"

- **2026-06｜Weak Critics Make Strong Learners: On-Policy Critique Distillation for Scalable Oversight [5]**：明确把问题定位为"弱监督者无法为复杂输出提供可靠标签、偏好或最终判断，从而同时限制 weak-to-strong generalization 与 scalable oversight"，并提出把弱模型当作 **critic**（而非标签源）这一"更可处理的弱监督形式"。
  - 热度证据：`> 待核实`（候选块无引用数/star/榜单）。
  - 权威证据：arXiv 预印本（cs.AI），v2 版本；`> 待核实`（无 venue / 同行评审信息）。
  - 关注度：中——依据：直接命中"scalable oversight"主题词，且 v2 说明作者在持续修订；但无引用/榜单信号。
  - 推荐度：★★★★☆——主题相关度最高，且提出了"弱监督信号形态"这一关键变量，是 2026 年该支线最值得精读的条目。
- **2024-02｜Improving Weak-to-Strong Generalization with Scalable Oversight and Ensemble Learning [4]**：把可扩展监督（人类监督 vs 模型辅助监督）与集成学习组合用于 W2S。
  - 热度证据：`> 待核实`；权威证据：arXiv 预印本，`> 待核实`；关注度：中（W2S + scalable oversight + ensemble 三关键词同时命中）；推荐度：★★★★☆——是本批中"可扩展监督×集成"最早的可核实锚点。
- **2024-10｜EnsemW2S: Enhancing Weak-to-Strong Generalization with Large Language Model Ensembles [6]**：用 LLM 集成增强 W2S。
  - 热度证据：`> 待核实`；权威证据：arXiv 预印本（v3，说明多次修订）；关注度：中；推荐度：★★★☆☆——与 [4] 构成"集成路线"的两点连线，但缺少与 [5] 的直接对照实验证据。
- **2025｜Strong Empowered and Aligned Weak Mastered Annotation for Weak-to-Strong Generalization [11]**（AAAI 2025，DOI: 10.1609/aaai.v39i26.34955）
  - 热度证据：`> 待核实`；权威证据：**AAAI 2025 正式发表（同行评审）**——本批唯一 A 级权威条目；关注度：中（顶会正式发表，但无引用数可查）；推荐度：★★★★☆——若只读一篇，应选此篇以校准"W2S 是否已被学界正式接收"这一判断。

### 1.2 辩论式监督：理论效率有增量，实证仍是空白

- **2023-11｜Scalable AI Safety via Doubly-Efficient Debate [33]**：从计算复杂性角度刻画辩论式监督的效率条件。
  - 热度证据：`> 待核实`；权威证据：arXiv 预印本，`> 待核实`；关注度：中（作为 debate 路线的理论延续被引用）；推荐度：★★★☆☆——与 [35] 配对阅读可建立"debate 理论谱系"。
- **2025-11｜Aligning Artificial Superintelligence via a Multi-Box Protocol [19]**：提出多隔离系统互相验证的对齐协议。
  - 热度证据：`> 待核实`；权威证据：arXiv 预印本（cs.AI），`> 待核实`；关注度：低——**纯协议构想，无实验、无基准、无真机/真模型验证**；推荐度：★★☆☆☆——作为"ASI 对齐协议设计"思潮样本，不可当作已验证方法。
  - 证据轴提示：本条属于 skill 所强调的"**仅有演示/自评之外的更弱一档——仅有构想**"，不得写成进展性结论。

### 1.3 偏好学习与 RLHF 理论：增量在"假设放宽"

- **2024-02｜Online Iterative RLHF with General Preference Model [26]**：摘要自述"**不像多数前人工作那样假设存在奖励函数与来自 Bradley-Terry 模型的 oracle 偏好信号**"，改用 general preference oracle，并把 RLHF 表述为"**reverse-KL 正则化的两个 LLM 之间的 minimax 博弈**"。这是 RLHF 理论形式化的**假设放宽**，而非原始提出。
  - 热度证据：`> 待核实`；权威证据：arXiv 预印本（cs.LG，v3），`> 待核实`；关注度：中（RLHF 主线，被后续理论工作引用）；推荐度：★★★☆☆——用于说明"RLHF 今日被引用偏向理论修正"，不能替代 RLHF 奠基引用 [27]。
- **2023-12｜Iterative Preference Learning from Human Feedback: Bridging Theory and Practice for RLHF under KL-Constraint [29]**：KL 约束下 RLHF 的理论-实践桥接。
  - 热度证据：`> 待核实`；权威证据：arXiv 预印本（v4），`> 待核实`；关注度：中；推荐度：★★★☆☆——是理解"KL 约束是 RLHF 核心几何约束"的入口。
- **2026-02｜LLMs as High-Dimensional Nonlinear Autoregressive Models with Attention: Training, Alignment and Inference [20]**：为 LLM 训练/对齐/推理提供统一数学参考。
  - 热度证据：`> 待核实`；权威证据：arXiv 预印本（cs.LG），`> 待核实`；关注度：低；推荐度：★★☆☆☆——综述性质，可用于数学记号统一，非前沿方法。

### 1.4 校准与不确定性：以"集成"形式回归，但**未与对齐闭环**

- **2026-02｜Value Bonuses using Ensemble Errors for Exploration in RL (VBE) [30]**：维护一组随机动作价值函数（RQFs）的集成，用其**估计误差**构造 value bonus，提供 first-visit optimism 与 deep exploration；文中指出既有方法只在观察到更高 reward bonus 后才回溯性增大 bonus，无法鼓励首次访问。
  - 热度证据：`> 待核实`；权威证据：arXiv 预印本（cs.LG，2026-02-12，v1），`> 待核实`；关注度：低；推荐度：★★☆☆☆——与"深度集成/校准理论的奠基"只有方法论相邻性（都用集成做不确定性），**不可作为校准理论奠基引用**。
- **2023｜Learn to Accumulate Evidence from All Training Samples: Theory and Practice [31]**：证据累积的理论与实践。
  - 热度证据：`> 待核实`；权威证据：arXiv 预印本（v2），`> 待核实`；关注度：低；推荐度：★★☆☆☆——可作为"不确定性/证据累积"这一支线的旁证。
- **术语污染警示**：[14] 标题虽含 "Uncertainty…Calibration"，但对象是**多线 TRL 电磁校准的测量与模型不确定度传播（ISO GUM 框架）**，与 AI 置信度校准无任何关系。这提示：以 "calibration" 单词检索对齐文献会引入大量同名异义噪声，需强制加限定词（如 `confidence calibration LLM alignment`）。同理 [13] 为 2015 年基于 star 数的 GitHub 流行度度量框架，本报告将其仅作为"热度指标方法论"的历史参考，不用于任何对齐结论。

## 3. 蓝海与缺口（Blue Ocean & Gaps）

**一句话增量判断**：最大的蓝海不是"再造一个对齐算法"，而是**可扩展监督缺少统一、可复现的评测协议**，以及**"校准/不确定性"与"价值对齐目标"之间尚无人搭桥**。

1. **校准 × 对齐的交叉几乎无人区（最高杠杆缺口）**。本批 36 条来源中，与 AI 校准/不确定性直接相关的仅 [30]（RL 探索的集成误差）与 [31]（证据累积），**没有任何一条把 LLM 置信度校准与对齐干预（拒答、澄清提问、监督者可靠性加权）连接起来**。而 [5] 的核心痛点正是"弱监督者的判断不可靠"——这本质上是一个**校准问题**，却未被 [5] 显式建模。→ 高杠杆机会：把监督者的置信度校准直接用于可扩展监督的标签/信号加权。
2. **可扩展监督缺统一基准与可比口径**。[4][6][11] 各自使用不同的 W2S 设置与数据集，本批未出现任何跨工作共用的基准或榜单；[33][35] 的 debate 路线与 W2S 路线之间亦无可比实验。→ 谁先发布统一 harness，谁定义该子领域。
3. **辩论式监督的实证荒漠**。[35] 与 [33] 提供理论，但本批中**没有一条真实大规模人类/模型辩论实验的复现结果**。[19] 的 Multi-Box 协议更只是构想。→ 空白的实证赛道。
4. **奠基框架的检索/研究缺口（需在下一轮补齐）**：
   - **iterated amplification**：本批 36 条来源零命中 → 原始贡献与当代引用无法评估。`> 待核实`
   - **recursive reward modeling**：零命中。`> 待核实`
   - **ELK (Eliciting Latent Knowledge)**：零命中。`> 待核实`（这意味着"诚实性 / 潜在知识"这一支线在本快照中完全缺失，是**覆盖度风险**而非"该方向已死"）。
5. **多语言/跨文化安全对齐缺口**：[10] 指出 LLM 安全性在多语言之间并不均衡（"All Languages Matter"）。→ 价值对齐的"价值"本身存在文化与语言分布问题，而本批中**没有一条工作把多语言安全评测与 W2S/可扩展监督结合**。
6. **系统安全 vs 技术对齐的路线争议**：[36] 直接主张"AI 安全被困在技术术语里"，并以系统安全（system safety）视角回应 International AI Safety Report。这是**方法论层面的对立面**，也是本领域最被低估的批评入口。
7. **欺骗性能力与自我知识一致性作为"弱监督失效"的潜在成因**：[9] 研究 LLM 的欺骗性能力，[12] 研究 LLM 人格的自我知识与行动是否一致。二者与"监督者不可靠"直接相关，但在本批中**未被任何可扩展监督工作引用** → 跨支线未连接的缺口。

## 4. 瓶颈与拐点（Bottleneck & Inflection）

**一句话增量判断**：瓶颈已从"弱模型能力不足"**转移**到"弱监督信号的信息密度与可靠性"；拐点信号是监督信号形态由**二元标签 → 偏好 → critique/集成投票**的升级。

| 维度 | 瓶颈内容 | 可核查依据 |
|---|---|---|
| 监督信号质量 | 弱监督者无法给出可靠的标签、偏好或最终判断，同时限制 W2S 与 scalable oversight | [5] 摘要原话 |
| 评测可比性 | 无统一基准/harness，跨工作不可比 | [4][6][11] 各自设置；无共用榜单（`> 待核实`） |
| 理论–实证落差 | debate 有复杂性理论刻画，但无大规模复现证据 | [33][35] 理论 vs 本批无实验复现 |
| 透明度与可复现 | 厂商透明度实践需年度量化跟踪 | [3] 第三版指数 |
| 协议层空转 | ASI 对齐协议停留在构想层，无验证路径 | [19] 无实验 |
| 算力/成本 | 本批**无任何算力或成本数据** | `> 待核实` |

**拐点信号与判定**：
- **已观察到的信号（较大概率）**：2024 年 [4] 用"人类监督 vs 模型辅助监督 + 集成"做 W2S → 2024-10 [6] 用 LLM 集成 → 2025 [11] 被 AAAI 正式接收 → 2026 [5] 转向"弱模型作 critic 的 on-policy 蒸馏"。**信号链**：弱监督的**信号形态**正在从离散标签升级为**理由/critique**，这是该支线最清晰的拐点迹象。
- **尚未出现的拐点**：把**校准/不确定性**作为监督者可靠性的显式建模项。本批无证据，判定为"**拐点未到**"。
- **可证伪假设 [P]**：若到 2027-06 之前出现 ≥2 个独立团队在公开基准上报告"监督者置信度加权的 W2S 优于等权"，则"校准 × 可扩展监督"拐点成立；否则判定该交叉仍处无人区。依据链：[5] 已指出弱监督判断不可靠 → 可靠性即校准问题 → 但当前无工作显式建模 → 存在明确空白。置信度：低–中（受样本规模限制）。
