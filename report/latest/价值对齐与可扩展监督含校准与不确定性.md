## 3. 蓝海与缺口（Blue Ocean & Gaps）

**一句话增量判断**：本证据集暴露的最大缺口不是"某方法还不够强"，而是**"监督协议的评测"与"校准/不确定性度量"这两套语言尚未合流**——一个刚被基准化 [21]，一个在本证据集中完全缺席。

1. **缺口 A：校准/不确定性与监督协议没有共同评测面**
   - 证据：[21] 基准化的是"监督协议"；本证据集中**没有**任何条目把 ECE/Brier/选择性预测与监督协议联合度量 → `> 待核实` [8][21]。
   - 杠杆点：谁先把"监督者的校准曲线（calibration curve）"定义为协议质量的一等指标，谁就占据了**评测标准**位置 [21]。
2. **缺口 B：可解释性（SAE）→ 监督闭环的下游验证缺失**
   - 证据：[31][33] 改进的是 SAE 表示的结构属性，本证据集**未显示**任何条目用 SAE 特征去改善监督者判断或审计效率 → `> 待核实` [31][33]。
   - 杠杆点：把 SAE 特征作为**辩论中的证据引用单元**，目前本证据集内无对应工作 [9][31][33]。
3. **缺口 C：辩论的"真实前沿模型 + 多轮 + 第三方复现"** `[Debated]`
   - 分歧：[9] 提供理论可扩展性，[23][24] 给出弱—强设定下的经验结果，但**两者是否可外推到同规模前沿模型的多轮辩论场景，本证据集无法判定** → `> 待核实` [9][23][24]。
4. **缺口 D：说服性攻击 / 监督者被说服 / 欺骗性对齐 / 对齐伪装（alignment faking）/ 奖励黑客**
   - 本证据集**零来源** → `> 待核实`。这是本报告最明显的覆盖失败项，须优先补检。
5. **缺口 E：企业部署约束下的监督（多租户、权限、审计留痕）**
