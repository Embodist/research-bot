### 1.3 方法演进脉络（基于现有证据重构）

1. **模块化感知-规划-控制**（~2020） →  
2. **端到端行为克隆 / 模仿学习**（ACT, Diffusion Policy, BC-Z，2022-2023） →  
3. **大规模跨本体预训练 + 语言条件**（RT-1, Open X-Embodiment, RT-2，2022-2023） →  
4. **视觉语言动作基础模型**（VLA：RT-2, Octo, OpenVLA，2023-2024） →  
5. **世界模型辅助预测与规划**（GEM-4D, What-If World, ForeTime-VLA，2025-2026） →  
6. **推理时干预与蒸馏部署**（Attention Steering, ForeTime-VLA 蒸馏，2026）  

> **不确定**：步骤 4-6 的主流采纳度与真机 SOTA 仍依赖于 **独立复现与基准榜单验证**，当前多为预印本宣称。[7][8][10][11][12][20]

## 4. 瓶颈与拐点

| 瓶颈维度 | 现状与证据 | 拐点信号 | 置信度 | 引用 |
|----------|------------|----------|--------|------|
| **数据规模与质量** | Open X-Embodiment 等数据集推动预训练，但真机高质量轨迹仍稀缺；AgiBot World Colosseo [6] 尝试大规模平台 | **大规模真机数据采集平台标准化 + 自动化标注管线** 出现 | 中 | [6] |
| **世界模型训练目标与下游任务错位** | 视频生成损失 ≠ 任务成功率；GEM-4D [20] 引入几何先验、What-If World [12] 引入因果基准，尝试缩小鸿沟 | **任务感知的世界模型目标（如价值感知预测、策略引导预测）** 成为主流 | 中 | [12][20] |
| **推理算力与实时性** | VLA 模型参数量大（>1B），端侧部署需量化/蒸馏/剪枝；ForeTime-VLA [8] 通过蒸馏压缩至 π0.5 | **专用推理加速器（NPU/TPU）+ 模型压缩协同设计** 使 7B 级 VLA 达到 >30Hz 真机控制 | 中高 | [8] |
| **Sim-to-Real 评测缺失** | 当前基准多为仿真内榜单，缺乏系统性真机对齐度量 [26] | **RSS/CoRL 设立 Sim-to-Real 专项基准赛道**，要求提交真机复现报告 | 高 | [26] |
| **安全与可解释性** | 端到端 VLA 为黑箱；Attention Steering [7] 为推理时干预探索 | **形式化验证 + 推理时护栏 + 世界模型反事实推理** 组合成标准安全栈 | 中 | [7][12] |

> **拐点预测**：若 **2026 年底前** 出现 **“在 ≥3 种本体、≥10 个长时程任务上，真机成功率 >90% 且单模型部署”** 的开源系统，将标志着 **世界模型赋能 VLA 进入工程化拐点**；反之仍处学术探索期。[P]
