## 1. 进展与热点（Progress & Hotspots）

**一句话增量判断**：相对以 TD-MPC2 [15] 为代表的"latent dynamics + 连续控制"基线，2025–2026 的增量不在"预测更准"，而在**把世界模型接到操作任务的三个不同接口上**——(a) 作为**动作可执行性判据**（视频世界模型必须物理一致）[1]；(b) 作为**带动作标注的合成数据引擎**[19]；(c) 作为**与动作联合建模的 world-action model，并从固定基座扩展到腿式移动操作**[6]；同时领域首次出现专门综述 [8]，标志术语开始收敛。

**相对上一基线的净增量（可核查部分）**：

1. **判据变化**：从"预测误差/回报"（TD-MPC2 路线 [15]）转向"生成未来的物理一致性"，GEM-4D 把"能否跨时间跟踪同一物理点"显式设为操作可用性门槛 [1]。这是本批证据中最清晰的方法论增量。
2. **接口变化**：世界模型不再只做 planner 的内部模型，而被当作**数据生产器**（Grounded-Dreamer [19]）与**动作联合预测器**（DECOWAM [6]）。
3. **本体变化**：从固定基座机械臂扩展到腿式移动操作，且明确诊断"相机自运动 vs 本体动作"未区分是旧模型的结构缺陷 [6]。
4. **学科化**：出现专门综述 [8]，且通用世界模型侧的"是否真是世界模拟器"争论已有系统梳理 [5]。
5. `> 待核实`：DreamerV3 / UniSim 与本批新工作的定量对比（成功率、任务数、硬件）在候选证据中完全缺失。

## 3. 蓝海与缺口（Blue Ocean & Gaps）

**一句话增量判断**：最大的无人区不是"生成更真实的视频"，而是**"世界模型输出的可执行性缺乏统一度量"**——[1] 提出了失败模式但没有给出可比指标，本批证据中也没有任何榜单承接这一度量 [1]。

1. **物理一致性的度量真空**：GEM-4D 明确指出视频世界模型"看似合理却缺乏可靠动作执行所需的物理 grounding"，根因是无法跨时间一致跟踪同一物理点 [1]；但点跟踪误差、接触/穿透率、任务成功率的口径与硬件条件在候选证据中均未给出 → `> 待核实`。**谁能定义这个指标，谁就定义这个赛道。**
2. **合成数据的动作标注保真度**：Grounded-Dreamer 以"真实采集贵 / 仿真视觉真实度有限 / 人类视频缺本体特定标注"三条受限路径为动机 [19]，但合成数据与真机数据的分布差距、是否需要真机微调，摘要层面未说明 → `> 待核实` [19]。深度侧的同源问题由 RealD²iff 用扩散反转噪声模式处理 [4]，可作为"数据保真"子方向的路标。
3. **移动/全身 world-action 是明确空白**：DECOWAM 直接断言"现有 world-action model 多为固定基座平台，未显式区分相机自运动与基座/臂动作" [6]——这是一条**作者自述的领域空白**，指向腿式移动操作、全身控制这一高杠杆方向。
4. **跨本体可比性无承接**：综述 [8] 应给出 taxonomy 与基准盘点，但本批证据未读到其正文/表格 → `> 待核实`；因此"哪些基准能支撑跨本体比较"在本报告内**无法作答**。
5. **安全/信任评测缺口**：工业会议已把 safety/trust 列为核心挑战 [23]，但本批证据无任何世界模型安全评测协议 → 空白。

## 4. 瓶颈与拐点（Bottleneck & Inflection）

**一句话增量判断**：瓶颈已从"模型容量/训练稳定性"（TD-MPC2 时代的问题域 [15]）**迁移到"物理一致性与评测可比性"**；但拐点**尚未确认**，因为本批证据中第三方复现数与榜单数均为 0。

| 瓶颈 | 证据 | 是否临近拐点 | 拐点信号 |
|---|---|---|---|
| 物理/几何一致性 | 视频世界模型无法跨时间跟踪同一物理点，导致生成不可执行 [1] | 早期（有诊断、无标准指标） | 出现被多篇工作共用的点跟踪/接触一致性指标 `> 待核实` |
| 数据规模化 | 遥操作贵、仿真真实度低、人类视频缺本体动作标注 [19]；深度 sim2real 噪声 [4] | 中期（合成数据路线已提出） | 合成数据训练的策略在真机零样本/少样本成功 `> 待核实` [19] |
| 评测可比性 | 本批证据 0 榜单、0 第三方复现 [1][6][19] | 未到拐点 | 公开榜单出现 world-model-based 操作条目 |
| 本体覆盖 | 现有 world-action model 以固定基座为主 [6] | 早期 | 同一模型在固定基座+移动本体上均报告结果 [6] |
| 安全/可信 | 工业会议将 safety/trust 列为核心挑战 [23] | 未到拐点 | 出现针对世界模型预测的安全评测协议 `> 待核实` |
| 术语与概念混淆 | "生成视频=世界模型"之辩已被系统梳理 [5] | 正在收敛 | 综述 [8] 的 taxonomy 被后续工作普遍采用 |
