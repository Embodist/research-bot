# 前沿进展追踪（Frontier Tracking）

## 目标
回答「最近 12-24 个月，这个方向发生了什么真正重要的变化？」

## 信息源分层
| 层级 | 来源 | 用途 |
|------|------|------|
| 一手论文 | arXiv (cs.RO / cs.LG / cs.CV / cs.AI)、OpenReview、CoRL/RSS/ICRA/ICLR/NeurIPS/CVPR | 方法首创、指标 |
| 代码与权重 | GitHub（stars/最近提交）、HuggingFace Hub | 是否开源、是否可复现 |
| 数据集/榜单 | Open X-Embodiment、DROID、LIBERO、SimplerEnv、RoboArena | 可比性 |
| 产业动态 | 官方博客、发布会、技术报告 | 真机部署、产品化 |
| 社区解读 | 知乎/公众号/Reddit/Twitter 线程 | 快速定位热点与争议 |

## 时间线组织法
1. 先按 `年份-季度` 排序关键节点（模型发布、数据集发布、榜单刷新）
2. 标注每个节点的「证据强度」：官方论文 / 技术报告 / 仅有演示视频
3. 对每个 SOTA 追问：在什么 benchmark、什么硬件、多少任务、是否真机

## 判断「真前沿」的四问
1. 是否在**多个任务/多个本体**上验证，而非单任务调参？
2. 是否开源（代码/数据/权重）？复现难度如何？
3. 相比上一代，提升来自数据、架构还是算力？能否归因？
4. 是否有独立第三方评测（榜单、复现报告）？

## 输出要求
- 「最新进展」与「经典工作」严格分节
- 每条进展给出：名称、时间、机构、链接 [n]、一句话贡献
- 结尾列「值得持续关注的 Watchlist」
