# 跨领域知识地图（Knowledge Framework）

## 何时使用
当任务不是"追踪某条前沿"，而是**理解一个领域/概念/定理/方法本身**时使用：背景是什么、要解决什么问题、
方案如何演进、核心机制与边界、如何评估、怎么落地、如何演进。目标是让读者（甚至跨领域的人）能据此
**建立可推敲的模型**，而不是记住一堆结论。

## 核心原则
1. **结构固定 → 可比较、可演进**：所有领域都用同一套 facet，因此不同领域的知识地图能横向对照，
   新知识也能直接补进既有槽位。
2. **结论必须可推敲**：每条论断带 `[n]`；取不到写 `> 待核实`，**不得编造**。
3. **边界即知识**：说不清"何时不适用/反例"的机制，等于没讲清。
4. **演进必带代价**：任何"解决了 X"的方案，都要交代它**新引入了什么代价/问题**（闭环）。

## 七维 facet（报告必须逐维展开）

| # | facet | 必须回答 |
|---|-------|----------|
| 1 | 定位与背景 Positioning | 定义（what it **is** / **is NOT**）、它为何存在、依赖哪些**前置知识体系** |
| 2 | 问题域 Problem Space | 它要解决的**核心问题**、问题的形式化表述、关键约束与不变量 |
| 3 | 历史与演进 Evolution | 时间线/代际；**每一代解决了什么、又新引入了什么**（代价闭环） |
| 4 | 核心机制 Mechanism | 概念/原理/定理/范式、关键**权衡**、**作用域**（何时适用/何时不适用、反例）、**失败案例** |
| 5 | 证据与评估 Evaluation | 指标/基准/可复现性、可解释性、**反例与失败模式**、争议与分歧 |
| 6 | 实践与生态 Practice | 经典工作与人物、工具与库、落地案例、**学习路径**（前置顺序）与**能力地图** |
| 7 | 关联与元层 Meta | 与相邻领域的关系与边界、该领域知识**如何被验证/推翻**、开放问题、**问题树**与演进方向 |

## 知识性质标记（区分知识的种类，避免混淆）
每一维内的关键条目，尽量标注其**知识性质**：

```text
[F] Fact          事实（可核查、无争议）
[P] Principle     原理/定理/定律
[M] Model         模型/范式/心智模型
[H] Hypothesis    假设/待验证
[E] Evidence      证据（实验/基准/数据）
[Heuristic] 经验规则（好用但非普适）
[Convention] 约定（人为规定，非自然律）
[Unknown] 未知
[Debated] 存在争议
```

## 对不确定内容保持 epistemic humility
证据不足时按档位明确表态，**不要用确定的语气讲不确定的事**：

```text
确定：……        （有权威来源/证明支撑，带 [n]）
较大概率：……    （多条间接证据一致）
推测：……        （合理外推，缺直接证据）
未知：……        （现有检索无结论）
需要实验：……    （只能靠实验/基准才能定）
```

## 学习与掌握（方向1 的核心产物）
在 `实践与生态` / `关联与元层` 两维里，必须给出可直接执行的"学会"路径：

- **前置知识链**：学这个之前必须先掌握什么（列成有序链，缺一环就点明）。
- **能力地图**：掌握后你**能做什么**（可检验的能力点，而非"了解"）。
- **问题树**：把这个领域的关键问题组织成树——主干问题 → 子问题 → 尚未解决的叶节点。
- **失败知识**：专家踩过的坑、典型失败案例、反直觉之处（这是新手最缺、最高价值的部分）。
- **高杠杆压缩**：先给出 **20 条**核心要点，再压缩成 **5 条**，最后压成 **1 句话**——压缩本身就是理解。

## 每条论断的纪律
- 事实性结论 → 带 `[n]` 引用；无论是定理、版本、基准数字还是历史事实。
- 机制/结论 → 至少给一个**适用边界或反例**；没有边界说明的，标注 `> 边界待核实`。
- `历史与演进` → 用"代际"组织：`第 N 代：解决 A；代价/新问题 B`，逐代成对，形成闭环。
- `证据与评估` → 尽量挂到**可测指标/基准/证明标准**上（如编译期开销、Sim2Real gap、证明严格性）。
- 不确定的因果、未定论的分歧 → 标 `[Debated]` 并写成"存在争议"，不要单方面下结论。

## 输出结构
严格按 facet 顺序产出 Markdown（章节标题即上表七项）。开篇用 3-6 条 *摘要* 给出这个领域最核心的
判断；每维内部：先给结论、再给证据与边界；术语首次出现给中英对照，专有名词保留英文。
