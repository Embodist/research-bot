# 论文调研与综述（Paper Survey）

## 从综述入手
1. 先找该方向 2-5 篇代表性 Survey / Review（arXiv `survey`、`review`、`taxonomy`）
2. 用综述的 taxonomy 作为分类骨架，再用最新论文补全
3. 注意综述时效：>2 年的综述可能漏掉基础模型时代的新范式

## 建立论文图谱
对每篇关键论文记录：

| 字段 | 说明 |
|------|------|
| 标题 / 年份 / 会议或期刊 | 出处可信度 |
| 作者 / 机构 | 是否领域核心团队 |
| 核心贡献 | 一句话，避免堆砌 |
| 方法关键词 | 架构/训练范式/表征 |
| 实验设置 | 仿真 or 真机、任务数、本体 |
| 开源情况 | 代码/数据/权重链接 |
| 引用数 | 影响力参考（注意时滞） |

## 脉络梳理法
- **按方法演进**：模块化 → 端到端 → 基础模型 → 统一动作空间
- **按监督信号**：模仿学习 / RL / 自监督 / 世界模型
- **按本体**：机械臂 / 灵巧手 / 移动 / 人形
- 用「承上启下」句式说明每篇相对前作改了什么

## 引用纪律
- 只引用真实存在且链接可达的论文
- arXiv 预印本标注 `(preprint)`，已中稿标注会议
- 引用编号与检索结果一一对应，禁止编造

## 常见陷阱
- 把 demo 视频当实验证据
- 混淆仿真 SOTA 与真机 SOTA
- 忽略失败案例与复现困难（negative results 也要写）
