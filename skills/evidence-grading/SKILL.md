# 证据分级（Evidence Grading）

## 分级标准
| 等级 | 证据类型 | 可信度 |
|------|----------|--------|
| A | 同行评审论文（RSS/CoRL/ICRA/NeurIPS…）、官方技术报告 | 高 |
| B | arXiv 预印本、官方 GitHub 仓库、官方数据集主页、厂商官方博客 | 中高 |
| C | 第三方复现、基准榜单、权威媒体深度报道 | 中 |
| D | 个人博客、社区帖子、聚合站、二手翻译 | 低 |
| E | 无法访问/内容为空/仅标题 | 不可用 |

## 冲突处理
1. 两个来源矛盾时，优先采信等级更高者，并在正文注明分歧
2. 数字类结论必须以一手表格/榜单为准，不用二手转述
3. 时间敏感结论（SOTA、版本号）以最新官方来源为准

## 表述纪律
- A/B 级证据 → 可直接陈述
- C 级证据 → 加限定词「据报道 / 第三方评测显示」
- D 级证据 → 仅作线索，必须另找高等级来源，否则标注 `> 待核实`
- E 级证据 → 丢弃

## 每条发现应携带的元数据
`point`、`evidence`、`sources`(引用编号)、`type`、`confidence`、`year`
confidence 与证据等级对应，不得夸大。
